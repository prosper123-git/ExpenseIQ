💰 ExpenseIQ

A Full-Stack Expense Manager Built with Node.js, Express, and Vanilla JS.

## Overview

ExpenseIQ is a full-stack expense management application originally built as a group project (Group 23), converted from a Java/Node.js console app into a modern Express-powered web app. It combines a clean, glassmorphism-styled frontend with a REST API backend, giving users a fast and intuitive way to track, organize, and review their expenses.

## Project Identity

**ExpenseIQ**
Built by: Prosper (Group 23)
Repo: [github.com/prosper123-git/ExpenseIQ](https://github.com/prosper123-git/ExpenseIQ/tree/main)

ExpenseIQ started life as a Java/Node.js console application and was rebuilt from the ground up into a full-stack Express application — pairing a REST API backend with a polished, glassmorphism-styled HTML/CSS/JS frontend.

## Key Features

- 💸 **Expense Tracking** — Add, view, and manage expenses through a clean web interface
- 🌐 **REST API Backend** — Express-powered API serving all data operations
- 🎨 **Glassmorphism UI** — Modern, translucent-styled frontend built with HTML/CSS/JS
- 🔄 **Console-to-Web Migration** — Rebuilt from a Java/Node.js console app into a full-stack web app
- 📦 **Structured Project Layout** — Organized under a dedicated `expenseiq/` folder

## Technologies

- **Node.js** — JavaScript runtime for the backend
- **Express** — REST API framework
- **HTML / CSS / JavaScript** — Glassmorphism-styled frontend, no framework overhead
- **REST API** — Clean separation between frontend and backend

## Installation

Make sure you have **Node.js** and **npm** installed before you run the following commands.

```bash
git clone https://github.com/prosper123-git/ExpenseIQ.git
cd ExpenseIQ
npm install
npm start
```

Then open your browser and navigate to the local server address (e.g. `http://localhost:3000`) to start using ExpenseIQ.

> If you run into issues, please reach out via GitHub issues.
